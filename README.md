# ProSpace — биржа фриланса

FastAPI · PostgreSQL (asyncpg + SQLAlchemy 2, Alembic) · Redis · Celery · Jinja2 · Pydantic · pandas + matplotlib · Docker.

## Быстрый старт (Docker)

```bash
cp .env.example .env            # задайте SECRET_KEY
docker compose up -d --build
docker compose exec web python -m app.cli demo   # демо-пользователи
```

- сайт: http://localhost:8010
- письма (коды подтверждения): Mailpit — http://localhost:8025
- демо-логины: `client`, `support` (сотрудник поддержки), `dev1`…`dev12`, пароль `Prospace#2026`
- выдать права поддержки: `python -m app.cli make-staff <username>`

## Локальная разработка

```bash
docker compose up -d db redis mailpit       # Postgres на хост-порту 5433
uv sync
uv run alembic upgrade head
uv run python -m app.cli demo
uv run uvicorn app.main:app --reload
uv run celery -A app.worker.celery_app worker -B -l info   # модерация и таймеры
uv run pytest                                # нужны db и redis
```

## Как реализовано ТЗ

**Регистрация / вход.** Имя и фамилия обязательны, email подтверждается 6-значным кодом (Redis, 15 мин, 5 попыток), username уникален без учёта регистра, пароль: ≥ 8 символов, строчная, заглавная, цифра, спецсимвол. Вход по username или email, сброс пароля кодом на почту.

**Кабинеты.** Роль переключается в профиле — меняется шапка и разделы. У заказчика: баланс, уведомления, мои заказы (поиск / взяты исполнителем / история), «Новый заказ», чат, поддержка. У исполнителя: доступные заказы (страница по умолчанию), в работе, история. Время последнего захода пишется автоматически (не чаще раза в минуту), онлайн = активность за 5 минут. Смена пароля — по коду с email.

**Деньги.** Размещение: 100 ₽ + сумма заказа уходят в резерв. Снятие до назначения исполнителя возвращает всё; после назначения сумма возвращается через отклонение заказа и окно спора, 100 ₽ остаются бирже. Отклик: 50 ₽, возвращаются, если исполнителя не выбрали. Комиссия 5% удерживается при выплате. Каждое движение — строка в `transactions`.

**Безопасная сделка.** Заказчик принимает работу → оплата исполнителю. Отклонение заказа или истечение срока без приёмки открывает окно спора на 2 часа: заказ нельзя снять. Исполнитель может открыть спор, поддержка решает его в течение 24 часов (просрочка эскалируется сотрудникам). Без спора деньги после окна возвращаются заказчику.

**Подбор исполнителей** (`services/matching.py`). Фильтры: категория, цена ≥ минималки исполнителя (не ниже 1000 ₽), статус «свободен», был в сети ≤ 4 ч назад, ещё не получал этот заказ, сейчас его рабочие часы. Скоринг: рейтинг 35%, выполненные заказы 25%, недавность захода 15%, частота реакции на предложения 20% (сглаженная — игнорирующие опускаются ниже), случайная доля 5%. Слоты: 7 опытных + 3 новичка (< 3 выполненных заказов, ранжируются отдельно) с добором из другой группы. Предложение живёт 2 часа (точный Celery-таймер + страховочный тик); молчание = отказ. Освободившийся слот сразу получает следующий кандидат. Лимит 5 откликов в сутки, неиспользованные копятся максимум за 2 суток, отказ заказчика возвращает отклик. Подбор останавливается при выборе исполнителя, при 10 откликах (`ORDER_RESPONSE_LIMIT`) или через 72 ч (`SELECTION_DEADLINE_HOURS`).

**Модерация и ИИ-агент.** Каждый заказ проходит цепочку модераторов. Правила (запрещённые услуги, контакты вне биржи, слишком короткое ТЗ) работают всегда. Чтобы подключить ИИ-агента на Claude, задайте `AI_MODERATION_ENABLED=true` и `ANTHROPIC_API_KEY`: агент возвращает структурированный вердикт `approve / reject / manual`. При сомнении, отказе модели или недоступности API заказ уходит на ручную проверку в `/staff/moderation`. Своего агента добавляют как класс с методом `async review(order) -> Verdict` в `build_pipeline()`.

**Уведомления.** Все события из ТЗ (отклики, «через 5 часов срок», работа отправлена, новые предложения, вас выбрали, принята, отклонена, правки) пишутся в историю. Онлайн приходит push через WebSocket и браузерное уведомление. Копия уходит на email, если пользователь не отключил это в профиле. Мобильное приложение может подписаться на тот же канал Redis `user:{id}`.
